# Chenghao (Cade) Li

Personal research portfolio, built with static HTML and CSS for GitHub Pages.

## Local preview

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Open http://127.0.0.1:8765. No build or dependencies are required.

## Updating content

- `index.html`: introduction, selected work, experience, publications & tech blog, education.
- `stylesheet.css`: responsive layouts, system dark mode, reduced-motion and print styles.
- `data/resume.pdf`: CV download (currently the October 9, 2026 CV).
- `data/ShenghaoLi-bio.txt`: short biography; the historical filename is retained for existing links.
- `images/featured/`: project imagery. PikaStream artwork comes from https://pika.art/blog/introducing-real-time-video-chat; Pika 2.5 imagery comes from https://pika.art/apps/pika-2-5. Pikaformance uses a CSS illustration, not a model output.

Older papers and projects are preserved in expandable sections. Research videos use native playback controls and load on demand. The original academic site was adapted from Jon Barron's website: https://github.com/jonbarron/jonbarron_website.

GitHub Pages publishes the site from the root of the `main` branch.
